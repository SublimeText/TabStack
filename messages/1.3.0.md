1.3.0 (2026-10-17)
------------------

TabStack now supports native Wayland sessions!
Because Wayland does not let applications query the keyboard state,
detecting the Ctrl release requires a small helper program
that you build and install yourself,
since it needs elevated capabilities to read the input devices.
Run "TabStack: Set Up Ctrl Detection for Wayland" from the Command Palette
to review its source and get the setup instructions.

The new `preview_tabs` setting controls
whether the highlighted tab is shown while moving through the quick panel.
Set it to `false` to stay on the current tab
until the switch is committed.
